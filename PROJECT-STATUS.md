# ArticleGrove project status

Included:
- Responsive public editorial website
- Homepage, articles, categories, search, article detail pages
- About, contact, privacy and terms starter pages
- Sanity client integration with published-only GROQ queries
- Separate Sanity Studio schemas for articles and categories
- SEO metadata, canonical paths, Open Graph, Twitter cards, JSON-LD, robots and sitemap
- Security headers are not yet configured at hosting level; configure them before production
- No public admin/publishing route and no write token in the frontend

Important:
- The public website displays sample articles until Sanity credentials are configured.
- Replace all sample content and contact details before launch.
- Newsletter form is a visual placeholder; it does not collect or store email addresses.
- Privacy and terms pages are starter templates, not legal advice.
- This ZIP is source code, not a deployed website. Install dependencies and test locally.
